# Umpan balik

Di akhir setiap halaman materi ada tiga tombol: **Terlalu berat**, **Pas**, **Terlalu ringan**. Halaman ini mengumpulkan semua penilaianmu.

Data hanya tersimpan di browser ini (`localStorage`), tidak dikirim ke mana pun. Ekspor ke JSON atau CSV kalau ingin membagikannya, misalnya untuk merevisi halaman yang terasa terlalu berat.
