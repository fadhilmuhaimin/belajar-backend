# --- F. Password harus diganti: menghapus file tidak mengubah password ---
# persiapan: role rekeningo_app dengan password lama, seperti database di VPS sejak minggu 1.
# Koneksi dibuka dari mesin lab lewat TCP (psycopg), jadi Postgres benar-benar memeriksa password;
# baris psql di bawah adalah padanan koneksi itu.
$ psql "postgres://rekeningo_app:<password dari git show 80952b1:.env>@db/lab" -c 'SELECT current_user'
-> masuk sebagai rekeningo_app

$ psql -c "ALTER ROLE rekeningo_app PASSWORD '<password-baru>'"
ALTER ROLE
$ psql "postgres://rekeningo_app:<password dari git show 80952b1:.env>@db/lab" -c 'SELECT current_user'
-> ditolak: password authentication failed for user "rekeningo_app"
$ psql "postgres://rekeningo_app:<password-baru>@db/lab" -c 'SELECT current_user'
-> masuk sebagai rekeningo_app
